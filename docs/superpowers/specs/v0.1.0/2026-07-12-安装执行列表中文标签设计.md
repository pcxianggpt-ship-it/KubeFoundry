# 安装执行列表中文标签设计

## 目标

安装执行模块的步骤列表中，“目标”和“执行方式”显示中文文本，同时保持后端接口和安装执行器使用的英文枚举值不变。

## 实现设计

在前端 `App.vue` 中维护目标范围和执行方式的显示映射，并通过格式化函数渲染表格单元格。

目标范围映射如下：

| 接口值 | 显示文本 |
| --- | --- |
| `primary_control_plane` | 主控制节点 |
| `all_nodes` | 所有节点 |
| `all_k8s_nodes` | 所有 Kubernetes 节点 |
| `control_plane` | 控制节点 |
| `non_primary_k8s_nodes` | 非主控 Kubernetes 节点 |
| `registry` | 镜像仓库节点 |
| `other_control_planes` | 其他控制节点 |
| `workers` | 工作节点 |

执行方式映射如下：

| 接口值 | 显示文本 |
| --- | --- |
| `serial` | 串行 |
| `parallel` | 并行 |

如果后端以后返回尚未映射的新值，前端直接显示原值，避免显示为空并保留排查信息。

## 测试与验证

前端组件测试覆盖目标和执行方式的中文显示，并确认英文枚举不再作为这两个表格单元格的可见文本。执行前端测试和生产构建，最后检查修改文件保持 LF 换行符。
