# UI 重构与验收记录

## 设计与实现

以用户确认的 Apple 风格红色失败版本为设计依据，参考图为 `image/Apple官网风格-v6-v3红色与无编号子任务.png`。本次直接修改现有 Vue 前端。

- 顶部横向导航替代桌面侧栏，嵌套配置和任务路由保持对应导航高亮；窄屏使用可展开菜单。
- 公共界面统一银灰背景、白色内容区、蓝色操作按钮和系统字体，配置列表、表单、组件配置及确认页沿用同一组颜色变量。
- 安装进度置于紧凑的居中区域，进度条高度为 6px。
- 主部署单元保留 1、2、3 等编号；子任务使用状态图标，不显示编号。
- 完成及验证跳过使用绿色，执行中使用蓝色，失败及中断使用红色，等待及依赖跳过使用灰色；同时保留文字说明。
- 日志改为浅色区域；明确的 ERROR/FATAL 标记或错误级别使用红色文字和浅红背景。普通信息中的“失败”字样不会自动视为错误级别。
- 保留节点退出码、诊断、步骤和节点日志筛选、刷新快照、定位失败位置、续跑新任务及来源任务入口。
- 长部署单元、步骤名称继续换行。节点记录为空时显示明确提示，表格与日志支持键盘滚动。

后端接口、安装步骤排序、任务状态机和 SSH 操作未改动。预览数据位于仓库外的临时服务中，不进入生产代码。

### 设计对照与有意差异

参考图为 1485×1059 像素；实现主截图为 1488×1056 像素、设备倍率 1。3px 的尺寸差和原生滚动条不视为设计偏差。

首轮存在较重的外层卡片、占用整行的失败提示、偏短的进度条和灰色导航选中态。已改为 400px 左分栏、760px 最大进度条、蓝色导航下划线，并将定位入口移入节点区。后续对照同时检查整页、失败步骤和错误日志局部。

| 对照项目 | 结论 |
| --- | --- |
| 字体与排版 | 系统字体及中文回退，标题 28px、主步骤 16px、子步骤 14px、日志 13px；实际诊断信息采用适合表格密度的字号 |
| 间距与布局 | 顶部导航 65px，进度区 181px，左分栏 400px；去除初版重卡片，窄屏转为上下布局 |
| 颜色 | 银灰与白色为主体；失败仍为红色。红色略深于效果图纯红，确保浅红背景上的普通文字对比度约 4.59:1 |
| 资产与图标 | 无照片、插画或背景资产；字标为可编辑产品名，标准状态图标复用 Element Plus 图标库，无自制 SVG |
| 文字与内容 | 使用真实接口字段及现有中文状态，不将效果图的固定节点、示例 IP、18/30 计数硬编码到页面 |

节点表保留实际接口提供的退出码与诊断，而不是效果图中的 IP/角色列；5 个模拟节点比参考图 3 个节点占用更多纵向空间。续跑入口及来源提示也比参考图多。这些是保留产品能力的有意差异。待执行采用时钟图标表达等待，子任务始终不带数字。
