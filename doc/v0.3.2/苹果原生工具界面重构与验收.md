# 苹果原生工具界面重构与验收

## 实现范围

2026-10-02 按用户指定的 `image/已有方案-苹果原生工具.png` 重构现有 Vue 前端。在已有未提交修改上继续调整界面。

用户已确认按此方案实施。方案已落入 `web/frontend/src` 的正式布局、任务页面、节点与日志组件及公共样式，并包含父步骤编号、节点状态圆点和可搜索节点筛选。生产构建已输出到 `web/frontend/dist`；正式代码继续通过现有 `/api` 接口读取业务数据，模拟接口仅用于本地界面验收。

- 桌面使用固定浅灰侧栏，产品名与版本位于顶部；配置、安装导航显示图标与蓝色选中背景。连接状态由现有健康接口驱动，每 30 秒检查，卸载时停止。
- 公共界面统一白色工作区、浅灰分组、细边框、系统字体和蓝色操作色。原文本框中性灰聚焦边框保留。
- 安装页增加顶部路径与返回集群入口；标题与状态左对齐，10px 进度条横向铺开。任务编号移入路径栏，避免与百分比重叠。
- 父步骤使用带顺序数字的圆形标记及连接线，圆形背景保留步骤状态色；展开单元内的子步骤使用状态图标，当前步骤呈蓝色选中态，失败呈红色。安装确认的计划列表同样显示编号。
- 节点表展示节点名称、IP、角色、执行状态和查看日志入口。IP 与角色来自当前节点配置；任务历史记录仍提供执行状态、退出码和诊断。配置读取失败时继续显示任务记录，缺失配置显示 `-`。
- 退出码和诊断移到表格下方可展开区域，支持键盘操作。
- 日志节点筛选使用固定宽度、可搜索的下拉框，默认显示节点总数，并与步骤筛选及刷新放在同一工具栏，保留步骤筛选、刷新、连接状态和错误高亮。级别显示为独立列；仅去除消息开头已显示的级别标记，其余消息保留。
- 窄屏使用抽屉导航及上下布局，表格在自身区域滚动，筛选控件按窄屏宽度分行。

未修改后端、部署脚本、步骤排序、任务状态机和 SSH 行为。预览接口位于仓库外，所有预览写操作只修改内存。用户确认后已重新生成独立命名的离线发布包，仓库原有发布包保留。

后续服务器反馈涉及续跑快照校验，已单独修复后端参数生成不一致，并调整顶部入口和左侧滚动。最新发布包与验证边界见 [续跑快照校验与进度页优化](续跑快照校验与进度页优化.md)。

## 设计复核

参考与实现截图均为 1487×1058 像素，CSS 视口同尺寸、设备倍率 1。初轮发现字号偏小、步骤缺少连接线、任务编号与百分比靠得太近，均已修正并重新截图。

系统字体在 Windows 上回退到 Segoe UI / Microsoft YaHei；主标题 40px、主步骤 20px、子步骤与节点 16px、日志 13px。标准图标复用 Element Plus；无照片、插画或背景资产。

保留现有业务文案、实际步骤计数及诊断能力，因此步骤名称、计数、节点状态、日志内容与参考示例不同。日志区域额外保留连接状态、步骤筛选与刷新工具，节点表额外保留查看日志入口。这些为保留产品能力的有意差异。蓝色和绿色文字采用稍深色值以保证可读性；旋转、等待图标使用现有图标库，属于轻微图标外观差异。

## 多节点筛选优化

根据用户反馈，取消逐台排列的节点按钮，改为可搜索节点下拉框。节点数量增加时不新增顶层控件；全部节点显示总数，原节点表查看日志入口仍可同步选择节点。桌面节点、步骤和刷新位于一行，320 窄屏自动分行。16 台节点的日志筛选与恢复全部节点测试通过；浏览器验证搜索 worker-01、日志切换、恢复全部节点、无应用错误和窄屏无整页横向溢出。

效果见 [紧凑节点筛选](../../../image/苹果原生工具-紧凑节点筛选.png)。

根据最新反馈，初始化环境、安装容器运行时等父步骤始终显示顺序数字，子步骤继续显示状态图标。节点表按用户提供的状态截图显示小圆点与文字：成功为绿色圆点与“已完成”，失败为红色圆点与“失败”，两者文字均使用中性色；运行中保留蓝色，等待与跳过保留原有语义。
