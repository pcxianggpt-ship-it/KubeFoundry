## 5. 阻断项与后续验收

### 5.1 v0.3.2 x86_64 候选包

2026-08-23 已统一后端、前端、健康接口、打包脚本、部署脚本和 README 的发布版本，并生成：

```text
文件：dist/kubefoundry-web-v0.3.2-x86_64.tar.gz
架构：x86_64
大小：126138860 字节
SHA-256：5ee61e239cba00e5a11338c7da81ea36ec95b31e8770065d5538bd5dae033a20
```

隔离构建首次发现发布包缺少 `scripts/lib/verify.sh`，导致双重验证引擎测试失败；已补齐隔离构建、正式归档和部署校验清单。重新构建后，后端 222 项、前端 58 项、双架构结构测试及包内 Java 运行时冒烟均通过。

真实环境随后发现离线仓库不包含 `sshpass`。安装阶段已改为只从离线仓库安装 `httpd`，密码首连和密钥分发继续由 Java SSH 节点测试负责；同时将 chmod 调整到 httpd RPM 安装之后，防止 RPM 重设 Web 目录权限。k8sc1 在未安装 `sshpass` 的条件下已通过 YUM 源步骤和 verify。
