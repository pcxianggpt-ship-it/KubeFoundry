# 安装步骤状态回放修复

## 问题与原因

安装任务进入详情页或断线重连后，部分已完成步骤仍显示“执行中”，节点计数却显示全部完成，所属阶段也无法显示完成。

现场 job3 的 CoreDNS 反亲和步骤在 2026-10-02 14:10:43 已成功，退出码为 0。首次 SSE 连接只回放了前 100 条历史事件，其中最后一条是 CoreDNS 的 running 事件（ID 213），后续 success 事件（ID 216）没有补发。页面先加载当前状态，再被旧 running 事件覆盖。

## 修复行为

- SSE 按事件 ID 递增分页读取，每页最多 100 条，持续补发直到历史事件读完，再订阅实时事件。
- 历史回放与实时订阅继续使用同一任务锁，防止交接期间遗漏或倒序发送事件。
- 回放支持 Last-Event-ID 请求头及 last_id 查询参数，从指定事件之后继续，不重复发送已接收事件。
- 回放遇到任务结束事件后完成连接；安装脚本与已保存的步骤状态无需修改。

## 验证与上线

JobEventApiTest 覆盖首次连接与断线续传跨越 100 条、200 条边界的完整有序回放，以及多页回放后继续接收实时事件和任务结束事件。新增测试在旧实现上可复现遗漏历史事件的问题；修复后该测试类全部 8 项测试通过。

部署需要更新后端并重启服务。服务器有安装任务运行时，应待任务结束后再部署，避免服务重启中断安装。本修复未改动安装状态机；未安排 Sol 独立并发专项复核。
