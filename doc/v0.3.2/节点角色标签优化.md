# 节点角色标签优化

## 实现

2026-10-04，按用户对安装任务节点表的反馈，将角色纯文字改为图标和文字组成的轻量标签，沿用现有节点配置界面的配色：控制平面蓝色、工作节点绿色、镜像仓库琥珀色，NFS 服务紫色。工作节点标签文字加深，保证小字号对比度。

多角色分别显示，空间足够时同行，不足时自动换行。角色继续从节点配置读取；配置未返回时沿用执行记录中的角色，未知角色原样显示，缺失角色显示 `-`。标签只用于展示。

2026-10-05 补充：NFS 角色从已保存、已启用的内部 NFS 组件配置派生，接口在所选非草稿节点的角色列表中返回 `nfs_server`，标签名称统一为“NFS 服务器”。选择外部服务器或禁用 NFS 后移除该标签，基础节点角色保留。完整规则见《NFS服务器位置与角色分配》。

按后续要求，集群配置的服务器节点角色也同步使用相同图标和配色。配置页与安装任务页共用 `NodeRoleBadge.vue` 组件及统一样式，保留配置页“控制节点”和安装页“控制平面”的原有业务名称。

## 验证

- 30 项界面与安装流程回归测试通过，覆盖多角色、未知角色、缺失角色和配置回退。
- 最终生产构建通过，保留现有依赖注释和产物大小提示。
- 浏览器以本地模拟任务检查四种角色及双角色节点；320 / 768 / 1024 / 1440 视口无整页横向溢出，标签内容无横向溢出。
- 角色文字与标签底色对比度均大于 4.5:1；状态仍采用圆点与文字，与角色标签区分。
