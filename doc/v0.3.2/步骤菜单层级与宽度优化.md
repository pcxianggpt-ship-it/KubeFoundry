# 步骤菜单层级与宽度优化

## 需求与实现

2026-10-04，按用户最终提供的“紧凑折叠”参考图实施。父阶段保留数字圆标，完成数量放在标题下面，状态图标和文字放在右侧；成功显示“已完成”。菜单默认保持白底，父阶段展开使用侧边细线标记。按后续反馈，二级菜单向左微调 8px，相对父编号缩进约 16px；选中的二级菜单整行使用浅蓝底色，取消原来的侧边细线，失败状态仍保留红色文字和图标。子任务采用名称、状态同行布局及细分隔线。

桌面步骤栏从 324px 调整到 400px，821–1200px 视口使用 320px，820px 以下切换上下布局。窄屏状态放到标题下方右侧，让长标题获得更多空间。

同一时间只展开一个阶段，点击已展开阶段可收起。选择子任务或切换步骤筛选时展开所属阶段；刷新步骤状态不会重新打开其他阶段。

## 验证

- 83 项前端测试通过，包括单阶段展开、折叠、状态刷新和子任务定位回归。
- 最终生产构建通过；保留原有依赖注释及产物体积提示。
- 320 / 768 / 1024 / 1440 四种视口无整页横向溢出，子步骤内容无横向溢出。
- 浏览器验证父阶段切换、子任务选择及默认白底效果；后续反馈调整为选中子任务整行浅蓝。桌面参考四个父标题均为单行。
- 使用本地模拟任务进行界面验收，未进行服务器部署验证。
