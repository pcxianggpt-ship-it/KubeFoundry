# 续跑快照校验与进度页优化

## 问题与修复

用户反馈点击“从失败处续跑”返回 `RESUME_SNAPSHOT_MISMATCH`，提示“安装路径或运行参数已变化”；同时要求入口移到页面上端，左侧步骤栏增加滚动条。

已在本地后端集成测试复现相同错误：启用存储与日志组件时，创建安装快照会将 MinIO 容量、CPU、内存等参数注入每个节点的运行环境；续跑校验只使用基础运行参数，因此配置未变也被判定不一致。

续跑校验改为复用 `InstallationSnapshotService.previewPayload` 的完整参数生成逻辑。保持对集群配置、组件配置版本、节点身份及凭据、运行参数和步骤计划的校验；实际参数变化仍拒绝续跑。继续创建新任务并原样复制来源快照，不修改来源任务或快照。

“从失败处续跑”移到进度页顶部标题右侧，窄屏自动换行，保留提交中禁用和防重复提交行为。左侧步骤列表增加受视口高度约束的独立纵向滚动区域，支持键盘聚焦及滚动；底部返回入口保留在滚动区域外。

- 16 项安装流程前端回归通过：顶部唯一入口、底部无重复入口、独立滚动区可聚焦、防重复提交、错误展示及成功后路由跳转。
