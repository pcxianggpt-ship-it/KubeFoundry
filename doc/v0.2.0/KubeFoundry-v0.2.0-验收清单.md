# KubeFoundry v0.2.0 验收清单

## Java 后端与数据

- [x] Spring Boot 3.3、Java 17、H2 与 Flyway 启动成功。
- [x] 集群、节点、设置、任务、阶段、事件和预检查结果持久化。
- [x] 节点密码使用 AES-256-GCM 加密，API 不回显密码或密文。
- [x] 每集群 Ed25519 密钥加密保存，主密钥与私钥具备 Linux 权限约束。
- [x] Java SSH/SFTP、主机指纹和免密配置不依赖系统 `sshpass`。

## 安装编排

- [x] 固定 14 步安装计划替代 Python `main` 入口。
- [x] containerd、依赖等阶段支持有界并发执行。
- [x] 同集群预检查/安装任务具备数据库级原子准入。
- [x] 远端脚本、参数、资源目录和符号链接边界有自动化测试。
- [x] 服务重启将遗留活动任务恢复为 `interrupted`。

## 网页向导

- [x] 五阶段流水线：首页、集群信息、节点、安装配置、预检查和安装入口可恢复。
- [x] 节点新增、编辑、复制、删除、密码保存语义和中文免密状态完整。
- [x] 预检查成功自动进入安装确认页，但不会自动启动安装。
- [x] 安装确认要求主动核对风险，安装任务进入独立执行页。
- [x] 执行页支持快照恢复、SSE、阶段/节点筛选、失败定位和日志查看。
- [x] 375px、768px、1024px、1440px 布局检查无控件重叠或整页横向漂移。

## API 与自动化证据

- [x] Java API 契约覆盖健康、集群、节点、设置、预检查、安装、任务和日志。
- [x] 前端客户端仅保留 Java 控制器支持的接口，路径与 HTTP 方法有契约测试。
- [x] 日志目录边界、大小限制和敏感字段脱敏有自动化测试。
- [x] Java 全量 138 项测试通过，0 失败、0 错误；Windows 条件跳过 19 项，Oracle Linux 9.5 仅跳过 1 项。
- [x] 前端全量 38 项测试通过，生产构建通过。
- [x] Bash CLI 路由、固定 API Server 端口及 Java Web 冒烟脚本语法检查通过。
- [x] 真实 x86_64 发布包在 Linux 环境完成健康、前端、深层路由、H2 创建和重启恢复冒烟。
- [x] 部署脚本拒绝架构不匹配、校验和被篡改、越界符号链接及测试运行时进入生产。
- [x] 正式 systemd 服务通过 Java SSH 对两台 Kylin V10 节点完成密码连接、公钥安装、密钥复连和系统信息采集。

## 离线包与真实环境

- [x] 生成并校验 `kubefoundry-web-v0.2.0-x86_64.tar.gz`，包内 Java 为 x86-64 ELF。

- [x] Kylin V10 x86_64 完成 systemd、SSH 和节点免密验证；服务重启后 H2 数据、加密凭据、首页和深层路由均正常。
- [ ] Kylin V10 ARM64 完成同等真实验证；当前尚未提供 ARM64 服务器，不得用静态检查替代。
- [x] 全部纳入提交的文本文件为 LF，代码和文档不包含真实密码、私钥、令牌或调试数据。

## 发布判定

M1 至 M4 已完成。M5 的实现、双架构真实二进制包和 Kylin V10 x86_64 动态验收已完成；ARM64 实机证据仍缺失。ARM64 外部条件补齐前，v0.2.0 不得标记为双架构真实验收全部通过。
