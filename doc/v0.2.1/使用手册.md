# KubeFoundry v0.2.1 使用手册

## 集群配置

从“集群配置”创建或打开集群，按以下顺序完成：

1. 保存集群名称、说明、Kubernetes `1.30.14`、Registry 类型和 Kubernetes 工作目录。
2. 添加服务器节点并完成节点测试。每个节点可选择控制节点、工作节点和 Registry 角色；控制节点与工作节点不能同时选择。
3. 保存 Kubemate 组件选择。v0.2.1 仅保存配置，不会安装 Loki、Traefik 或 NFS。
4. 执行配置预检查。成功后进入同一集群的“集群安装”。

Pod 网段固定为 `10.244.0.0/16`，Service 网段固定为 `10.96.0.0/16`。Registry 信息由唯一的 Registry 角色节点派生，端口固定为 `5000`。

## 集群安装

“集群安装”展示最近的预检查、安装和重置任务。安装前会重新校验拓扑、介质、节点测试结果和配置版本，并创建不含凭据的配置快照。安装成功后配置将锁定；安装失败不会产生持久锁。

## 远程重置

远程重置会按任务快照清理 Kubernetes、Registry 和受管目录，属于不可恢复操作。提交前必须：

1. 勾选风险确认。
2. 输入精确短语 `RESET <集群名称>`。
3. 在任务执行页等待所有节点完成。

只有全部节点重置成功后才会解除配置锁并恢复为草稿状态。失败或服务中断会保留锁定和任务日志，修复节点问题后可重新确认并重试。
