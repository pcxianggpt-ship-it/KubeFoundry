# KubeFoundry v0.2.1 集群配置与安装模块开发计划

## 1. 计划目标

本计划用于实施《集群配置与安装模块设计》，完成配置与安装模块拆分、固定网络参数、安装配置收敛、节点多角色、Registry 信息派生、Kubemate 配置页面、安装成功锁定和远程重置任务。

实施采用测试先行和小步提交。每个任务完成后必须运行对应测试；涉及数据库迁移、安装状态机、SSH 或远程删除的变更必须进行专项评审。

## 2. 全局约束

- Java 17、Spring Boot 3、H2、Flyway、Apache MINA SSHD 技术栈保持不变。
- 前端继续使用 Vue 3、Element Plus、Vue Router、Vitest 和 Vite。
- 继续复用 Bash 安装脚本，远程重置新增独立 Bash 步骤。
- 所有文本文件使用 Linux LF。
- `doc/` 下文档使用中文名称并归档到 `doc/v0.2.1/`。
- 不修改既有 Flyway V1 至 V7，只能新增迁移。
- 不覆盖用户已有工作区改动。
- Git 提交说明使用中文。
- Kubemate 在 v0.2.1 只保存和展示配置，不进入实际安装计划；实际组件安装属于 v0.3.0。
- 远程重置属于破坏性操作，未经强确认和后端校验不得执行。


## 15. 风险与控制

| 风险 | 影响 | 控制措施 |
| --- | --- | --- |
| 多角色迁移错误 | 安装步骤命中错误节点 | 保留旧列兼容窗口、迁移报告、目标解析测试 |
| Registry 与 Kubernetes 同机清理冲突 | 重置顺序错误或残留 | 角色集合驱动步骤、同节点单记录、专项测试 |
| 工作目录为空或越界 | 误删系统目录 | 后端规范化、白名单、脚本二次校验、危险路径测试 |
| 安装中读取实时配置 | 同一任务参数不一致 | 创建不可变任务快照，步骤只读快照 |
| 重置部分失败却解锁 | 配置与远端状态失配 | 全部成功才解锁，失败保持原锁并允许重试 |
| Kubemate 页面造成已安装误解 | 用户错误判断组件状态 | 显著版本提示、安装计划隔离、回归测试 |
| 历史 V7 锁定语义不一致 | 旧集群无法正确编辑 | 新增迁移按成功安装任务修正锁状态 |

## 16. 完成定义

只有同时满足以下条件，v0.2.1 才视为完成：

- 设计范围内全部任务和测试完成。
- 高风险远程重置经过专项安全评审。
- 所有生成文件为 LF。
- 中文文档与实际接口、状态和页面一致。
- Kubemate 组件不会被本版本安装。
- 安装成功后锁定、远程重置成功后解锁的闭环在专用测试集群验证通过。
- 没有遗留可以绕过远程重置而直接解锁的 API 或服务方法。
