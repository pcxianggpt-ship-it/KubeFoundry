# 界面换肤功能与验收

## 1. 功能与使用

2026-10-05，在本次 Apple 风格改版基础上加入两版外观切换。

| 外观 | 来源 | 导航与页面样式 |
| --- | --- | --- |
| 经典版 | 实施换肤时的 Git HEAD `68ac1e9`，即本次 Apple 改版前已提交的界面 | 保留左侧导航、原有字体、配色、间距、表格和执行页面样式；移动导航断点为 820px。 |
| Apple 版 | 本次 Apple 风格改版 | 保留黑色顶部导航、磨砂次导航、字体层级、白灰配色与圆角体系；移动导航断点为 833px。 |

Apple 版的“外观”入口位于次导航右侧；经典版位于左侧导航，小屏位于品牌标题下方。首次访问默认使用 Apple 版，在“外观”下拉框中选择“经典版”或“Apple 版”即可即时切换。

选择保存在当前浏览器的 `localStorage` 中，键为 `kubefoundry.ui-theme`。刷新、切换页面和重新打开后保留选择；无选择或存储值无效时回退 Apple 版。浏览器禁用存储时，当前会话仍可切换，刷新后恢复默认。

两版共用一个页面工作区，切换不会重新挂载业务页面，保留当前路由、未保存表单、已选步骤、日志节点筛选和任务事件连接。切换时关闭展开的移动导航，并在使用键盘换肤时将焦点交还新版本的换肤控件。

## 2. 实现范围

- `web/frontend/src/themes/classic.css`：从上述 HEAD 提取原有完整样式，仅添加主题选择器隔离并为动画名称增加主题后缀。已核对移除这些隔离标记后，选择器与声明和原版一致。
- `web/frontend/src/themes/apple.css`：保留本次 Apple 改版的完整样式，采用同样的隔离方式。根元素主题属性覆盖整个文档，也作用于弹窗、下拉菜单等挂载到页面外层的内容。
- `web/frontend/src/styles.css`：导入两版样式并维护换肤入口样式；为表头增加定位上下文，修复经典版屏幕阅读器隐藏文字引起的窄屏轻微溢出。
- `web/frontend/src/themes/theme.js`、`src/components/ThemeSwitcher.vue`：主题状态、偏好存储、可访问的原生选择控件。
- `web/frontend/src/main.js`、`src/layouts/AppShell.vue`：挂载前恢复主题，按主题展示导航，并保持主工作区实例。
- 对应主题、导航与安装确认响应式测试：覆盖偏好恢复、无效值、存储受限、切换保持页面状态、两版移动导航和焦点管理。

后端接口、安装脚本、配置保存与任务执行逻辑保持原有行为。

## 3. 验收

### 3.1 自动与浏览器检查

- 前端 20 个测试文件、101 项测试通过，生产构建通过；依赖已有的 PURE 注释与分包体积提示仍存在。
- `git diff --check` 通过，新增与修改文本使用 UTF-8 无 BOM、LF。
- 使用独立 Edge 无头浏览器访问本地样例预览：两版分别检查集群配置、集群安装、集群信息、服务器节点、组件配置、预检查、安装概览、安装确认、远程重置和安装进度，共 10 个页面。
- 分别检查 1440、1024、768、320px，合计 80 个页面与宽度组合，无整页横向溢出；另检查 827px 下两版不同的导航断点。
- 验证刷新恢复主题、无效存储回退、换肤入口焦点、两版移动菜单路由关闭与 Esc 返回焦点。
- 验证换肤保留表单草稿、页面元素实例、任务失败步骤、节点日志筛选，未因切换增加任务读取请求。
- 使用运行中样例与模拟事件源验证换肤后原任务事件连接仍保留，未关闭或新建连接。
- 两版鼠标点击文本框均保持灰色焦点边框。检查期间没有未捕获的页面脚本异常，没有非 GET 请求。
