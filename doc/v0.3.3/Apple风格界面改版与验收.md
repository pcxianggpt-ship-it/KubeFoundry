# Apple 风格界面改版与验收

## 1. 改版范围

2026-10-05，依据根目录 `DESIGN.md` 中的 Apple 风格视觉规范调整现有 Vue 前端。本文归档于 v0.3.3，前端包版本仍保持 0.3.2。

本次采用规范中的黑色顶部主导航、磨砂次导航、中性白灰背景、单一蓝色操作强调、字体层级与圆角体系。官网产品图片和整屏产品展示不适用于安装工作区，因此继续使用表格、配置表单和部署步骤列表承载业务信息。

### 1.1 具体调整

| 区域 | 调整内容 |
| --- | --- |
| 全局导航 | 左侧导航改为 44px 黑色顶部导航；52px 磨砂次导航展示所属模块、当前页面和版本；保留健康接口连接状态。 |
| 配色 | 主操作蓝色为 `#0066cc`，正文为 `#1d1d1f`，背景为 `#f5f5f7`；节点角色标签改为中性色；成功、失败、警告保留独立语义颜色及文字、图标。 |
| 字体 | 普通正文采用 17px 与 1.47 行高，桌面主标题采用 40px/600；表格、诊断、日志保留较紧凑字号；使用本地系统字体，无外部字体服务依赖。 |
| 控件 | 主按钮采用胶囊圆角；工具按钮与输入框采用 8px 圆角；主要内容区采用 18px 圆角、细边框，无装饰性渐变或投影。 |
| 配置工作区 | 四个配置阶段等宽展示；统一集群信息、服务器节点和组件配置的间距及标题层级。 |
| 安装概览 | 桌面五项状态摘要与实际内容数量对齐；主要安装入口突出显示，任务记录与重置能力保留。 |
| 执行页面 | 步骤列表和节点详情使用独立白色内容区；深色日志区配合适用于深色背景的日志级别颜色；保留步骤分组、失败定位、节点筛选、刷新与续跑入口。 |
| 安装确认 | 底部核对与开始安装区域采用磨砂面板样式，并保持正常文档流，避免遮挡节点、安装计划及风险提示。 |
| 窄屏 | 833px 及以下主导航折叠；任务详情改为上下布局；小屏表格在自身区域横向滚动，页面无整体横向溢出。 |
| 可访问性 | 保留跳至主内容、键盘焦点、菜单 `aria-expanded`、隐藏菜单 `inert` 和 Esc 返回按钮焦点；窄屏仍可读取连接状态；鼠标点击文本框保持中性灰色边框。 |

### 1.2 修改文件

- `web/frontend/src/layouts/AppShell.vue`：顶部导航与页面上下文展示。
- `web/frontend/src/themes/apple.css`：全局样式、控件、工作区、执行页面与响应式布局；后续加入换肤功能时从 `styles.css` 拆出并进行主题隔离。
- `web/frontend/src/layouts/AppShell.test.js`：更新导航选择器，验证页面上下文、移动端路由切换及焦点恢复。

接口、后端任务编排、安装脚本、凭据处理、安装状态规则、配置锁定与提交请求内容未作调整。

后续已加入“经典版 / Apple 版”外观切换，保留改版前已提交的完整界面。详见[界面换肤功能与验收](./界面换肤功能与验收.md)。下列验收记录为首次 Apple 改版时的检查结果，换肤后的最新结果见该文档。

## 2. 验收

### 2.1 自动检查

- 前端测试：19 个测试文件、92 项测试通过。
- 前端生产构建通过；仍有依赖包已有的 PURE 注释与分包体积提示。
- `git diff --check` 通过；本次修改的文本文件使用 UTF-8 无 BOM、LF 换行。

### 2.2 浏览器检查

使用独立的 Edge 无头浏览器与拦截的样例接口数据完成验收，所有非 GET 请求均被阻止，没有执行真实安装、续跑或远程重置。

- 检查集群配置列表、集群安装列表、集群信息、服务器节点、组件配置、预检查、安装概览、安装确认、远程重置及安装失败进度，共 10 个页面。
- 在 1440、1024、768 和 320px 四种宽度下检查，共 40 个页面与宽度组合，无页面整体横向溢出。
- 移动端导航切换后关闭菜单，Esc 关闭后焦点返回菜单按钮。
- 验证失败定位、按节点筛选日志和任务快照刷新。
- 文本框点击后的边框为 `rgb(134, 134, 139)`，没有蓝色描边。
- 样例浏览器检查没有未捕获的页面脚本异常。
- 检查集群列表空状态、加载失败与骨架加载状态。
