# KubeFoundry v0.3.0 接口说明

所有接口均由 Web 服务提供，默认地址为 `http://<管理端>:10001/api`。响应不会返回节点密码或私钥。

## 健康检查

```text
GET /health
```

成功响应包含 `status: "ok"` 与 `version: "0.3.0"`。

## 集群组件配置

```text
GET /clusters/{clusterId}/components
PUT /clusters/{clusterId}/components
```

读取接口返回组件组配置和安装状态。更新接口接收完整组件组配置；组件组定义由服务端目录控制，客户端不能写入未知组或不可用组。

## 安装计划与任务

```text
GET  /clusters/{clusterId}/install-plan
POST /clusters/{clusterId}/precheck
POST /clusters/{clusterId}/install
POST /clusters/{clusterId}/components/install
```

安装计划返回服务端计算的步骤、目标范围、执行模式和资源要求。预检查、基础安装和组件安装返回 `202 Accepted`，响应格式为：

```json
{"job_id": 123, "status": "pending"}
```

客户端不能指定安装步骤；基础安装的请求体中如包含非空 `steps` 将被拒绝。

## 任务查询

```text
GET /jobs?cluster_id={clusterId}
GET /jobs/{jobId}
GET /jobs/{jobId}/steps
GET /jobs/{jobId}/logs
GET /jobs/{jobId}/events
```

`/events` 使用 Server-Sent Events 返回任务状态和日志事件。日志接口会对已识别的敏感值进行脱敏。
