# KubeFoundry v0.3.0 使用手册

## 配置集群

1. 创建集群并保存名称、Kubernetes `1.30.14`、Registry 类型和 Kubernetes 工作目录。
2. 添加节点并完成节点测试。控制节点和工作节点不能同时分配给同一节点；Registry 可以与其中一个角色共存。
3. 在组件页选择需要的 Kubemate 组件组并保存配置。
4. 执行预检查。预检查通过后进入集群安装页。

Pod 网段固定为 `10.244.0.0/16`，Service 网段固定为 `10.96.0.0/16`。节点密码只用于首次节点测试，并以加密形式保存；后续操作使用集群私钥。

## 安装组件

新集群的基础安装会在 Kubernetes 就绪后编排已启用的组件组。已由 v0.2.1 安装的集群可在组件页保存配置并单独发起组件安装，不需要重置 Kubernetes。

组件介质由管理端的 `kube-media/` 提供。执行前，应用选择与主控制节点架构相符的 Helm，校验其 SHA-256，分发 Helm、Chart 或 YAML 至主控制节点，然后远程执行 `kubectl` 或 Helm。不要手工修改任务生成的受管标记、组件状态或快照文件。

安装任务按服务端计划运行，页面只显示计划，不能提交自定义步骤。失败后先查看任务、步骤和节点日志，修复介质、连通性或配置问题，再使用同一配置重新发起任务。

## 远程重置

远程重置不可恢复。提交前必须勾选风险确认并输入精确短语 `RESET <集群名称>`。重置会先依据安装快照和组件状态清理 KubeFoundry 受管组件，再执行 Kubernetes、Registry 和受管目录清理。

仅当全部节点的重置步骤成功时，配置锁才会解除并且组件状态回写为未安装。失败或服务中断时必须保留现场和任务日志，不要通过手工删除状态来解锁集群。
